このUSBは「AIにプロジェクトを引き継がせる」ための鍵。
あなたがやることは3ステップだけ。

## 1) 開く
引き継ぎたいプロジェクトのフォルダで、AI(Claude Code / Codex / Antigravity)を開く。

## 2) 言う(コピペ)

**【既存PJを再開する】**
> このUSBの AI_KEY/10_PROJECTS から引き継ぐPJを選ばせて。
> 選んだら AGENTS.md → docs/STATE.md の順に読んで、残作業から着手して。

→ AIが登録済みPJを一覧で出す。あなたは選ぶだけ。

**【新しいPJに規約を入れる】**
> このrepoに引き継ぎ規約(AGENTS/STATE/LOG)を dev-conventions のテンプレから入れて。

## 3) 終わったら
AIが docs/STATE.md と docs/LOG.md を更新し、コミット&Pushする(AIの義務)。
あなたは最後に **USB ⇄ Google Drive を同期**(正本=Drive、USB=写し)。
