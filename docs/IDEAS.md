1件は**詩**(散文でない1〜2文)＋**タグ2語以上**。書き方は `templates/docs/IDEAS.template.md`。
One entry = a poem (one or two lines, never prose) + **two or more grep tags**.

タグは詩の外に置く。詩は名詞を削ぎ落とす形式なので、**詩だけでは grep に掛からない**
(実例: 「索引は…」は `projects.md` を含まないまま `projects.md` の話をしている)。
Tags live outside the poem: poetry strips the very nouns you would grep for.

この棚は **dev-conventions 自身**の案だけを持つ。各プロジェクトの案はそのrepoの `docs/IDEAS.md`。
This shelf holds ideas about the convention itself; project ideas live in each project's repo.
